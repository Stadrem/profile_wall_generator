## 검증 범위

실행 취소·다시 실행은 백그라운드 Blender에서 명시적으로 기록 지점을 만든 뒤 `undo`와 `redo`를 호출했습니다. 실제 UI의 Ctrl+Z 입력, 연속 드래그 중 자동 갱신과 실행 취소의 타이밍까지 검증한 결과는 아닙니다.

Mesh Line의 Edit Mode 중 실시간 갱신 문제는 이번 수정 범위에서 제외했습니다. 원본은 Curve 사용을 권장합니다. Unity 내보내기, 대상 기기 성능, 다른 Blender 버전은 이번 검증에 포함하지 않았습니다.

자동 갱신 지연 테스트에서 출력되는 `Curve has no splines`는 잘못된 원본 입력 후 복구를 확인하는 의도된 사례이며, 테스트 실패가 아닙니다.
